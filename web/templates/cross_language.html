Cross-Language Analysis

Analysis Documentation

This feature combines the Gasket and Jelly tools to generate a unified Cross-Language Call Graph:

  • Jelly: Maps execution flows and function calls at the JavaScript level.
  • Gasket: Identifies the communication bridges (Native Bridges) between JavaScript and Native C/C++ modules.
  • Cross-Language Call Graph: Unifies the two levels, visualizing the calls that traverse the boundary from JavaScript to the Native code.
