Cross-Language Analysis

Τεκμηρίωση Ανάλυσης

Αυτή η επιλογή συνδυάζει τα εργαλεία Gasket και Jelly για την παραγωγή ενός ενοποιημένου Cross-Language Call Graph:

  • Jelly: Χαρτογραφεί τη ροή εκτέλεσης και τις κλήσεις συναρτήσεων στο επίπεδο της JavaScript.
  • Gasket: Εντοπίζει τις γέφυρες επικοινωνίας (Native Bridges) μεταξύ JavaScript και Native C/C++ modules.
  • Cross-Language Call Graph: Ενώνει τα δύο επίπεδα, απεικονίζοντας τις κλήσεις που διασχίζουν το όριο από την JavaScript στον Native κώδικα.
